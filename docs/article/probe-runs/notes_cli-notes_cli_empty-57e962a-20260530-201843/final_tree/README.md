# Программа для управления заметками

Этот проект представляет собой простой CLI-инструмент для добавления, просмотра, поиска и удаления заметок. Заметки хранятся в формате JSON.

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes.py add "Это моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```bash
python notes.py search "заметка"
```

### delete
Удаляет заметку по её индексу.

**Пример использования:**
```bash
python notes.py delete 1
```
