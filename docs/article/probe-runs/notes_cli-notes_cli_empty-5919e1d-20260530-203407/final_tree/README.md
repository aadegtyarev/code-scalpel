# notes-cli

Python CLI для заметок с JSON-хранилищем.

## Назначение

Это утилита для быстрого управления короткими текстовыми заметками из командной строки. Она должна поддерживать четыре команды:

- `add` — добавить новую заметку
- `list` — показать все заметки
- `search` — найти заметки по тексту
- `delete` — удалить заметку по идентификатору

## Хранилище

Заметки хранятся в JSON-файле. Рекомендуемый путь хранения — `notes.json` в рабочем каталоге проекта, если не задан другой путь через CLI или переменную окружения.

Ожидаемый формат данных:

```json
[
  {
    "id": "1",
    "text": "Купить молоко",
    "created_at": "2026-05-30T17:19:00Z"
  }
]
```

Минимально каждая заметка должна содержать:

- `id` — уникальный идентификатор
- `text` — текст заметки
- `created_at` — время создания

## Примеры команд

```bash
python -m notes_cli add "Купить молоко"
python -m notes_cli list
python -m notes_cli search "молоко"
python -m notes_cli delete 1
```

## Сценарии использования

- быстро записать мысль или задачу
- найти заметку по части текста
- удалить устаревшую запись
- просмотреть все заметки без открытия файла вручную
