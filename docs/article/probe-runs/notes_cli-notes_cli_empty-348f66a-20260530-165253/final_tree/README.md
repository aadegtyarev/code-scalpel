# Notes CLI

## Команды

1. **add**
   - Добавляет новую заметку.
   - Пример использования: `python notes.py add "Текст заметки"`

2. **list**
   - Выводит все сохраненные заметки.
   - Пример использования: `python notes.py list`

3. **search**
   - Ищет заметки по ключевым словам.
   - Пример использования: `python notes.py search "ключевое слово"`

4. **delete**
   - Удаляет заметку по идентификатору.
   - Пример использования: `python notes.py delete 1`

## Хранение заметок

Заметки хранятся в JSON-файле, который создается автоматически при добавлении первой заметки.
