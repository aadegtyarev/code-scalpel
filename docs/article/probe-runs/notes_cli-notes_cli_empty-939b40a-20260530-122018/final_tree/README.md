# CLI для заметок

Этот проект представляет собой простой командный интерфейс (CLI) для управления заметками. Заметки хранятся в файле `notes.json`.

## Команды

- **add**: Добавляет новую заметку.
  Пример использования: `python main.py add "Моя новая заметка"`

- **list**: Выводит список всех заметок.
  Пример использования: `python main.py list`

- **search**: Ищет заметки по ключевому слову.
  Пример использования: `python main.py search "ключевое_слово"`

- **delete**: Удаляет заметку по индексу.
  Пример использования: `python main.py delete 1`
