# notescli — заметки в терминале

Простой CLI для управления заметками. Хранит данные в JSON-файле, не требует внешних баз данных.

## Команды

### `add` — добавить заметку

```bash
python -m notescli add --title "Заголовок" --content "Текст заметки"
```

Создаёт заметку, присваивает уникальный ID и выводит его.

### `list` — показать все заметки

```bash
python -m notescli list
```

Выводит список заметок (ID + заголовок), отсортированных по дате создания.

### `search` — поиск заметок

```bash
python -m notescli search --query "подстрока"
```

Ищет заметки, в заголовке или тексте которых встречается `query`.

### `delete` — удалить заметку

```bash
python -m notescli delete --id <UUID>
```

Удаляет заметку по её ID. Сообщает об успехе или отсутствии заметки.

## Хранилище

Все заметки сохраняются в JSON-файл `notes.json` в текущей рабочей директории. При первом запуске файл создаётся автоматически.

Формат записи:

```json
{
  "id": "uuid-строки",
  "title": "Заголовок",
  "content": "Текст заметки",
  "created_at": "2026-01-01T12:00:00+00:00"
}
```
