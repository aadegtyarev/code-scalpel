# notes-cli

Консольная утилита для управления заметками. Хранит заметки в JSON-файле, работает целиком на стандартной библиотеке Python.

## Установка

```bash
pip install -e .
```

Для разработки (с pytest):

```bash
pip install -e ".[dev]"
```

## Использование

### Добавить заметку

```bash
notes add --title "Заголовок" --body "Текст заметки"
```

Создаёт новую заметку с уникальным ID и текущей датой.

### Список заметок

```bash
notes list
```

Выводит все заметки в формате `[ID] Заголовок (дата)`. Если заметок нет — выводит `Нет заметок.`.

### Поиск заметок

```bash
notes search --query "текст"
```

Ищет заметки, у которых заголовок или тело содержат указанный текст (регистр не важен). Выводит найденные заметки.

### Удалить заметку

```bash
notes delete --id 1
```

Удаляет заметку по ID. Если заметка не найдена — завершается с кодом 1 и сообщением об ошибке.

### Справка

```bash
notes --help
```

## Формат хранения

Заметки хранятся в файле `notes.json` в текущей директории. Формат — JSON-массив объектов:

```json
[
  {
    "id": 1,
    "title": "Заголовок",
    "body": "Текст заметки",
    "created_at": "2026-05-12T10:30:00"
  }
]
```

Поля:

- `id` — уникальный целочисленный идентификатор (автоинкремент).
- `title` — заголовок заметки (строка).
- `body` — тело заметки (строка).
- `created_at` — дата и время создания в ISO 8601.
