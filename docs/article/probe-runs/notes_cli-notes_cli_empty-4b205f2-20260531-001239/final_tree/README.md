# Notes CLI

Python CLI для заметок с JSON-хранилищем. Проект умеет создавать, показывать, искать и удалять заметки из локального файла.

## Команды

### add
Добавляет новую заметку.

Пример:

```bash
python -m notes_cli add --title "Идея" --text "Сделать заметку про CLI"
```

### list
Показывает все заметки.

Пример:

```bash
python -m notes_cli list
```

### search
Ищет заметки по подстроке в заголовке или тексте без учёта регистра.

Пример:

```bash
python -m notes_cli search "CLI"
```

### delete
Удаляет заметку по идентификатору.

Пример:

```bash
python -m notes_cli delete 42
```

## JSON-хранилище

Заметки сохраняются в JSON-файл как массив объектов. Каждая заметка содержит поля:

- `id` — уникальный идентификатор заметки
- `title` — заголовок заметки
- `text` — текст заметки
- `created_at` — время создания заметки

Пример содержимого файла:

```json
[
  {
    "id": "42",
    "title": "Идея",
    "text": "Сделать заметку про CLI",
    "created_at": "2026-05-31T12:00:00Z"
  }
]
```

## Назначение

Этот проект нужен как основа для простого локального менеджера заметок с тестируемой бизнес-логикой и файловым хранением.
