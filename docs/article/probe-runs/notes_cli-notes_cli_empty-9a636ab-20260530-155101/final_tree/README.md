# Программа для заметок

Это простое приложение на Python, которое позволяет добавлять, просматривать, искать и удалять заметки. Заметки хранятся в формате JSON.

## Команды

- `add <текст>`: Добавляет новую заметку.
- `list`: Показывает все существующие заметки.
- `search <поиск> <строка>`: Ищет заметки, содержащие указанную строку.
- `delete <номер>`: Удаляет заметку по её номеру.
