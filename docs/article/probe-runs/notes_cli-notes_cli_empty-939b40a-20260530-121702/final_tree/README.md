# Программа для работы с заметками

## Описание
Эта программа предоставляет простой интерфейс командной строки (CLI) для управления заметками. Заметки хранятся в JSON-файле.

## Команды
1. **add**: Добавить новую заметку.
   Пример использования: `python notes_cli.py add "Новая заметка"
2. **list**: Вывести список всех заметок.
   Пример использования: `python notes_cli.py list`
3. **search**: Найти заметки по ключевому слову.
   Пример использования: `python notes_cli.py search "ключевое слово"
