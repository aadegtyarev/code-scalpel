# Книжный клуб — Telegram-бот

Асинхронный Telegram-бот для управления книжным клубом: добавление книг, голосование, выбор текущей книги для обсуждения.

## Команды

### /start
Приветственное сообщение со списком всех доступных команд.

**Пример:**
```
/start
```
→ *«Добро пожаловать в Книжный клуб! Вы можете добавлять книги, голосовать, выбирать следующую книгу и многое другое.»*

### /add_book
Запускает диалог (FSM) для добавления новой книги. Последовательно запрашивает:
1. Название книги
2. Автора
3. Описание (кратко)

**Пример:**
```
/add_book
→ Введите название книги:
Мастер и Маргарита
→ Введите автора:
Михаил Булгаков
→ Введите описание:
Роман о любви, добре и зле, написанный в нескольких сюжетных линиях.
→ Книга "Мастер и Маргарита" добавлена!
```

### /vote
Отображает inline-клавиатуру с кнопками для каждой книги из базы. Нажатие на кнопку добавляет один голос выбранной книге.

**Пример:**
```
/vote
→ Голосуйте за книгу месяца:
[ Мастер и Маргарита ]
[ Преступление и наказание ]
[ 1984 ]
```

### /next
Переводит следующую по порядку книгу в статус «текущая» (is_current = 1). Остальные книги сбрасываются в is_current = 0.

**Пример:**
```
/next
→ Текущая книга: "Мастер и Маргарита"
```

### /list
Выводит список всех книг с количеством голосов у каждой.

**Пример:**
```
/list
→ Список книг:
1. Мастер и Маргарита (М. Булгаков) — 5 голосов
2. Преступление и наказание (Ф. Достоевский) — 3 голоса
3. 1984 (Дж. Оруэлл) — 7 голосов
```

### /reset_votes
Обнуляет количество голосов у всех книг.

**Пример:**
```
/reset_votes
→ Голоса всех книг сброшены!
```

## Хранение данных

Используется SQLite через библиотеку `aiosqlite` (асинхронный драйвер).

### Таблица `books`

| Поле         | Тип         | Описание                                    |
|-------------|-------------|---------------------------------------------|
| id          | INTEGER     | Первичный ключ, автоинкремент               |
| title       | TEXT        | Название книги                              |
| author      | TEXT        | Автор книги                                 |
| description | TEXT        | Краткое описание или аннотация              |
| votes       | INTEGER     | Количество голосов (по умолчанию 0)         |
| is_current  | INTEGER     | 1 — текущая книга для обсуждения, 0 — нет  |

Файл базы данных (`bookclub.db`) создаётся автоматически при первом запуске бота.
