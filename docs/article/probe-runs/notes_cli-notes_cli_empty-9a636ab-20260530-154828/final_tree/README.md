# CLI для заметок

Этот проект представляет собой простой командный интерфейс (CLI) для управления заметками. Заметки хранятся в формате JSON.

## Команды

- `add <текст>`: Добавляет новую заметку.
  Пример использования: `python notes.py add "Позвонить маме"`

- `list`: Отображает все заметки.
  Пример использования: `python notes.py list`

- `search <ключевое слово>`: Ищет заметки по ключевому слову.
  Пример использования: `python notes.py search "Позвонить"`

- `delete <идентификатор>`: Удаляет заметку по идентификатору.
  Пример использования: `python notes.py delete 1`

## Формат хранения данных

Заметки сохраняются в файле `notes.json` в формате JSON. Каждая заметка имеет уникальный идентификатор, текст и метку времени создания.

```json
[
  {
    "id": 1,
    "text": "Позвонить маме",
    "created_at": "2023-10-01T12:00:00Z"
  }
]
```
