# Notes CLI

Консольное приложение для управления заметками. Хранит заметки в JSON-файле, поддерживает четыре операции: добавление, просмотр списка, поиск и удаление.

## Установка

```bash
pip install -e .
```

## Использование

Все команды вызываются через `notes` (или `python cli.py`):

### add — добавить заметку

```bash
notes add "Купить молоко"
# Output: Note added with id 1
```

### list — показать все заметки

```bash
notes list
# Output:
# 1: Купить молоко (2026-05-11T12:00:00)
# 2: Позвонить маме (2026-05-11T12:05:00)
```

### search — найти заметки по тексту

```bash
notes search "молоко"
# Output:
# 1: Купить молоко (2026-05-11T12:00:00)
```

### delete — удалить заметку по ID

```bash
notes delete 1
# Output: Note deleted
```

Если заметка с таким ID не найдена:

```bash
notes delete 999
# Output: Note not found
# Exit code: 1
```

## Формат хранения

Данные хранятся в файле `notes.json` в текущей директории. Файл создаётся автоматически при первом добавлении заметки.

Структура записи:

```json
{
  "id": 1,
  "text": "Купить молоко",
  "timestamp": "2026-05-11T12:00:00"
}
```

- `id` — целочисленный уникальный идентификатор, автоинкремент.
- `text` — текст заметки (строка).
- `timestamp` — дата и время создания в формате ISO 8601.

Файл представляет собой JSON-массив таких объектов:

```json
[
  {"id": 1, "text": "Купить молоко", "timestamp": "2026-05-11T12:00:00"},
  {"id": 2, "text": "Позвонить маме", "timestamp": "2026-05-11T12:05:00"}
]
```

## Тестирование

Тесты написаны на pytest. Запуск:

```bash
pytest
```

Все тесты изолированы: каждая тестовая функция использует отдельный временный файл (через `tmp_path`), чтобы не влиять на другие тесты и не трогать реальный `notes.json`.
