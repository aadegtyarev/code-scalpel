# Notes CLI

## Описание
Это простой Python-CLI для управления заметками. Предоставляет следующие команды:

- `add <text>`: Добавить новую заметку.
- `list`: Вывести список всех заметок.
- `search <keyword>`: Поиск заметок по ключевым словам.
- `delete <index>`: Удалить заметку по индексу.

## Использование

### Добавление заметки
```bash
python notes.py add "Моя новая заметка"
```

### Вывод списка заметок
```bash
python notes.py list
```

### Поиск заметок
```bash
python notes.py search "заметка"
```

### Удаление заметки
```bash
python notes.py delete 1
```
