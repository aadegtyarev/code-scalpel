# Программа для управления заметками

Этот проект представляет собой командную строковую утилиту (CLI) для создания, просмотра, поиска и удаления заметок. Заметки хранятся в формате JSON.

## Команды

- **add**: Добавляет новую заметку.
  Пример использования: `python notes.py add "Новая заметка"`

- **list**: Выводит список всех заметок.
  Пример использования: `python notes.py list`

- **search**: Ищет заметки по ключевым словам.
  Пример использования: `python notes.py search "ключевое слово"`

- **delete**: Удаляет заметку по индексу.
  Пример использования: `python notes.py delete 1`

## Формат JSON-хранилища заметок

Заметки хранятся в файле `notes.json`, который представляет собой массив объектов. Каждый объект содержит следующие поля:

- **id**: Уникальный идентификатор заметки (генерируется автоматически).
- **text**: Текст заметки.
