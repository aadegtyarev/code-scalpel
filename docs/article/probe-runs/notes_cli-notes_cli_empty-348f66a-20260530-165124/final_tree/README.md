# Notes CLI

## Описание
Это простой Python-CLI для управления заметками. Предоставляет команды для добавления, списка, поиска и удаления заметок.

## Команды
- **add**: Добавить новую заметку.
  Пример: `python src/app.py add "Новая заметка"`
- **list**: Список всех заметок.
  Пример: `python src/app.py list`
- **search**: Поиск заметок по ключевому слову.
  Пример: `python src/app.py search "ключевое слово"`
- **delete**: Удаление заметки по индексу.
  Пример: `python src/app.py delete 1`

## Формат хранения данных
Заметки сохраняются в формате JSON в файле `notes.json`.

## Тестирование
Для тестирования используется pytest. Установка дополнительных зависимостей не требуется.
