# CLI для заметок

Этот проект представляет собой простой CLI инструмент для управления заметками. Доступны следующие команды:

## add
Добавляет новую заметку.

**Пример использования:**
```
python notes.py add "Моя первая заметка"
```

## list
Выводит список всех заметок.

**Пример использования:**
```
python notes.py list
```

## search
Ищет заметки по ключевому слову.

**Пример использования:**
```
python notes.py search "заметка"
```

## delete
Удаляет заметку по её идентификатору.

**Пример использования:**
```
python notes.py delete 1
```
