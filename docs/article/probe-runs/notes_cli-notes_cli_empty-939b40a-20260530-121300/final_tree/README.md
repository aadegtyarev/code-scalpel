# Программа для заметок

Этот проект представляет собой простой CLI для управления заметками. Заметки хранятся в формате JSON.

## Команды CLI

- `add <заметка>`: добавляет новую заметку.
  Пример использования: `notes add "Позвонить родителям"`

- `list`: выводит список всех заметок.
  Пример использования: `notes list`

- `search <ключевое слово>`: ищет заметки по ключевому слову.
  Пример использования: `notes search "звонить"`

- `delete <номер заметки>`: удаляет заметку по её номеру в списке.
  Пример использования: `notes delete 1`

## Формат JSON-хранилища

Заметки хранятся в файле `notes.json` в следующем формате:

```json
[
    {
        "id": 1,
        "text": "Позвонить родителям"
    },
    {
        "id": 2,
        "text": "Сделать домашнее задание"
    }
]
```
