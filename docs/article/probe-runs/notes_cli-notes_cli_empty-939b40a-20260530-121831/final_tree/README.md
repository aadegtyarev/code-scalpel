# Программа для заметок

Этот проект представляет собой простой Python-CLI для управления заметками. Он поддерживает следующие команды:

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes/cli.py add "Новая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes/cli.py list
```

### search
Ищет заметки по ключевым словам.

**Пример использования:**
```bash
python notes/cli.py search "ключевое слово"
```

### delete
Удаляет заметку по индексу.

**Пример использования:**
```bash
python notes/cli.py delete 1
```

## Формат данных
Заметки хранятся в файле `notes/notes.json` в формате JSON. Пример структуры:
```json
[
    {
        "id": 1,
        "text": "Первая заметка"
    },
    {
        "id": 2,
        "text": "Вторая заметка"
    }
]
```
