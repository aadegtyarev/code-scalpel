# CLI для заметок

Этот проект предоставляет простой интерфейс командной строки для управления заметками. Используется JSON-хранилище для сохранения данных.

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes.py add "Новая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```bash
python notes.py search "ключевое_слово"
```

### delete
Удаляет заметку по индексу.

**Пример использования:**
```bash
python notes.py delete 1
```
