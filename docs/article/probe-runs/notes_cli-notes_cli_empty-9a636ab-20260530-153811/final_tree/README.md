# Notes CLI

## Команды:

- **add**: Добавляет новую заметку.
  Пример: `python notes.py add "Это моя первая заметка"`

- **list**: Выводит список всех заметок.
  Пример: `python notes.py list`

- **search**: Ищет заметки по ключевым словам.
  Пример: `python notes.py search "заметка"`

- **delete**: Удаляет заметку по индексу.
  Пример: `python notes.py delete 1`
