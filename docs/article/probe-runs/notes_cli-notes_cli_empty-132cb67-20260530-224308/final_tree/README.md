# Notes CLI

Python CLI для заметок с JSON-хранилищем.

## Команды

- `add` — добавить заметку
- `list` — показать все заметки
- `search` — найти заметки по тексту
- `delete` — удалить заметку по идентификатору

## Хранилище

Заметки сохраняются в JSON-файл. По умолчанию путь к хранилищу задаётся самим приложением, а при запуске можно передать свой путь через аргумент CLI.

Ожидаемый формат данных:

```json
[
  {
    "id": "1",
    "text": "Купить молоко"
  },
  {
    "id": "2",
    "text": "Позвонить врачу"
  }
]
```

Каждая заметка содержит:

- `id` — уникальный строковый идентификатор
- `text` — текст заметки

## Примеры

Добавить заметку:

```bash
notes-cli add "Купить молоко"
```

Показать все заметки:

```bash
notes-cli list
```

Найти заметки:

```bash
notes-cli search "молоко"
```

Удалить заметку:

```bash
notes-cli delete 1
```
