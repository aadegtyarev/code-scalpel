# Notes CLI

## Описание
Этот проект представляет собой простой командный интерфейс для управления заметками. Заметки хранятся в формате JSON.

## Команды
- **add**: добавляет новую заметку.
  Пример использования: `python notes.py add "Новая заметка"`
- **list**: выводит список всех заметок.
  Пример использования: `python notes.py list`
- **search**: ищет заметки по ключевому слову.
  Пример использования: `python notes.py search "ключевое слово"`
- **delete**: удаляет заметку по индексу.
  Пример использования: `python notes.py delete 1`

## Формат JSON-хранилища
Заметки хранятся в файле `notes.json`, который представляет собой массив объектов, каждый из которых содержит текст заметки.

Пример содержимого `notes.json`:
```json
[
    {
        "text": "Первая заметка"
    },
    {
        "text": "Вторая заметка"
    }
]
```
