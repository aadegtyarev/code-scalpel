# Notes CLI

A simple Python-based CLI for managing notes.

## Commands

- `add <text>`: Add a new note.
  Example: `python notes/cli.py add "My first note"`

- `list`: List all notes.
  Example: `python notes/cli.py list`

- `search <keyword>`: Search for notes containing the specified keyword.
  Example: `python notes/cli.py search "first"`

- `delete <id>`: Delete a note by its ID.
  Example: `python notes/cli.py delete 1`
