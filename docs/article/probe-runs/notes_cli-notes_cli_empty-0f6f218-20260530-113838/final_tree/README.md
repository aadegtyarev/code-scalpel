# Программа для управления заметками

## Команды:

- `add <заметка>`: добавляет новую заметку.
- `list`: выводит список всех заметок.
- `search <ключевое слово>`: ищет заметки по ключевому слову.
- `delete <номер заметки>`: удаляет заметку по её номеру.

## Формат хранения данных:

Заметки хранятся в файле `notes.json` в формате JSON. Каждая заметка представляет собой строку текста.
