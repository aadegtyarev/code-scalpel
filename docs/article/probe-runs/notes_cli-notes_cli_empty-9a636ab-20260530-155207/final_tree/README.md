# CLI для заметок

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python main.py add "Это моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python main.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```bash
python main.py search "заметка"
```

### delete
Удаляет заметку по её индексу.

**Пример использования:**
```bash
python main.py delete 1
```

## Формат хранения данных
Заметки хранятся в файле `notes.json` в формате JSON-массива строк.

## Установка зависимостей
Для установки необходимых зависимостей выполните следующую команду:
```bash
pip install -r requirements.txt
```

## Запуск тестов
Для запуска тестов выполните следующую команду:
```bash
pytest tests/test_commands.py
```
