# Программа для работы с заметками

## Команды

- **add**: Добавить новую заметку
  ```bash
  python notes.py add "Текст заметки"
  ```

- **list**: Вывести список всех заметок
  ```bash
  python notes.py list
  ```

- **search**: Найти заметки по ключевому слову
  ```bash
  python notes.py search "ключевое_слово"
  ```

- **delete**: Удалить заметку по её индексу
  ```bash
  python notes.py delete 1
  ```
