# Python Notes CLI

CLI для заметок с JSON-хранилищем. Проект позволяет быстро добавлять заметки, просматривать список, искать по тексту и удалять по идентификатору.

## Команды

- `add` — добавить новую заметку
  - `python -m notes_cli add "Купить молоко"`
- `list` — показать все заметки
  - `python -m notes_cli list`
- `search` — найти заметки по тексту
  - `python -m notes_cli search "молоко"`
- `delete` — удалить заметку по id
  - `python -m notes_cli delete 42`

## Хранилище

Заметки сохраняются в JSON-файл. Ожидаемый формат — массив объектов, где каждая заметка содержит как минимум:

- `id` — уникальный идентификатор заметки
- `text` — текст заметки
- `created_at` — время создания

Пример содержимого файла:

```json
[
  {
    "id": "1",
    "text": "Купить молоко",
    "created_at": "2026-05-30T17:19:00Z"
  },
  {
    "id": "2",
    "text": "Позвонить врачу",
    "created_at": "2026-05-30T17:20:00Z"
  }
]
```

## Правила сохранения данных

- Каждая команда работает с одним JSON-файлом хранилища.
- `add` добавляет новую запись, не затирая существующие заметки.
- `list` и `search` только читают данные.
- `delete` удаляет заметку по `id` и сохраняет обновлённый список обратно в файл.
- Если хранилище ещё не создано, оно считается пустым.
- Формат файла должен оставаться валидным JSON после каждой операции записи.
