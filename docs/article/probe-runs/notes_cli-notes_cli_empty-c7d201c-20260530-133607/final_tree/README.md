# CLI для заметок

Этот проект представляет собой простой командный интерфейс (CLI) для управления заметками. Заметки хранятся в формате JSON.

## Команды

- `add <заметка>`: добавляет новую заметку.
- `list`: выводит все заметки.
- `search <ключевое слово>`: ищет заметки по ключевому слову.
- `delete <номер заметки>`: удаляет заметку по её номеру.

## Формат данных

Заметки хранятся в файле `notes.json` в формате JSON массива объектов, где каждый объект представляет собой заметку с полями:
- `id`: уникальный идентификатор заметки (число).
- `content`: текст заметки (строка).
