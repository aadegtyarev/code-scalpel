# CLI для заметок

## Команды:

- **add**: добавляет новую заметку.
  Пример использования: `python main.py add "Новая заметка"`

- **list**: выводит список всех заметок.
  Пример использования: `python main.py list`

- **search**: ищет заметки по ключевому слову.
  Пример использования: `python main.py search "ключевое_слово"`

- **delete**: удаляет заметку по её идентификатору (номеру в списке).
  Пример использования: `python main.py delete 1`

## Тестирование:
Для запуска тестов необходимо установить pytest. После установки можно запустить тесты командой:
```
pip install pytest
pytest tests/test_notes.py
```
