# CLI для заметок

Этот проект представляет собой простой CLI-инструмент для управления заметками. Заметки хранятся в формате JSON.

## Команды:

1. **add** - добавляет новую заметку.
   Пример использования: `python notes.py add "Текст заметки"`

2. **list** - выводит все сохраненные заметки.
   Пример использования: `python notes.py list`

3. **search** - ищет заметки по ключевому слову.
   Пример использования: `python notes.py search "ключевое_слово"`

4. **delete** - удаляет заметку по метке.
   Пример использования: `python notes.py delete "метка"
