# CLI для заметок

## Описание
Этот проект представляет собой простой Python-CLI для управления заметками. Он поддерживает следующие команды:

- `add <текст>`: добавляет новую заметку.
- `list`: выводит список всех заметок.
- `search <ключевое слово>`: ищет заметки по ключевому слову.
- `delete <индекс>`: удаляет заметку по её индексу в списке.

## Примеры использования

```bash
python app.py add "Запись первой заметки"
python app.py list
python app.py search "заметка"
python app.py delete 1
```
