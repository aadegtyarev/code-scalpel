# Python Notes CLI

A simple CLI tool for managing notes.

## Commands

- **add**: Add a new note.
  ```bash
  python notes.py add "This is my first note"
  ```

- **list**: List all notes.
  ```bash
  python notes.py list
  ```

- **search**: Search for notes containing specific keywords.
  ```bash
  python notes.py search "first"
  ```

- **delete**: Delete a note by its index.
  ```bash
  python notes.py delete 1
  ```
