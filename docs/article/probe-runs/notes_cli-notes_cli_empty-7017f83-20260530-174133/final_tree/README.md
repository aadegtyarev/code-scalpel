# CLI для заметок

Этот проект представляет собой простой Python-CLI для управления заметками. Предоставлены следующие команды:

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python main.py add "Моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python main.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```bash
python main.py search "заметка"
```

### delete
Удаляет заметку по идентификатору.

**Пример использования:**
```bash
python main.py delete 1
```
