# CLI для заметок

## Описание
Этот проект представляет собой простой Python-CLI для управления заметками. Он позволяет добавлять, просматривать, искать и удалять заметки с использованием JSON-хранилища.

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes/cli.py add "Это моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes/cli.py list
```

### search
Ищет заметки по ключевым словам.

**Пример использования:**
```bash
python notes/cli.py search "заметка"
```

### delete
Удаляет заметку по её индексу.

**Пример использования:**
```bash
python notes/cli.py delete 1
```
