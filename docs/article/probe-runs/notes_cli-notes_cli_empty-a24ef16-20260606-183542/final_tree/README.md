# Python CLI для заметок

Этот проект представляет собой простой CLI-инструмент для управления заметками. Он поддерживает следующие команды:

- **add**: Добавляет новую заметку.
  Пример использования: `python notes.py add "Моя первая заметка"`

- **list**: Отображает все существующие заметки.
  Пример использования: `python notes.py list`

- **search**: Ищет заметки по ключевым словам.
  Пример использования: `python notes.py search "ключевое слово"`

- **delete**: Удаляет заметку по идентификатору.
  Пример использования: `python notes.py delete 1`

## Установка

Убедитесь, что у вас установлен Python. Затем выполните следующие команды:

```bash
pip install -e .
pytest
```
