# Программа для работы с заметками

Этот проект представляет собой командную строковую утилиту (CLI) для управления заметками. Основные функции включают добавление, просмотр, поиск и удаление заметок.

## Команды

- **add**: Добавляет новую заметку.
  Пример использования: `python main.py add "Это моя первая заметка"`

- **list**: Выводит все сохраненные заметки.
  Пример использования: `python main.py list`

- **search**: Ищет заметки по ключевому слову.
  Пример использования: `python main.py search "заметка"`

- **delete**: Удаляет заметку по её идентификатору (ID).
  Пример использования: `python main.py delete 1`
