# Notes CLI

Python CLI для заметок с JSON-хранилищем.

## Назначение

Это утилита для работы с заметками из терминала. Она поддерживает команды:

- `add` — добавить заметку
- `list` — показать все заметки
- `search` — найти заметки по тексту
- `delete` — удалить заметку по идентификатору

## Примеры использования

```bash
notes add "Купить молоко"
notes list
notes search "молоко"
notes delete 1
```

## Хранилище

Заметки сохраняются в JSON-файл на диске. По умолчанию файл хранения лежит рядом с приложением и используется как постоянное хранилище между запусками.

Ожидаемый формат данных:

```json
[
  {
    "id": "1",
    "title": "Купить молоко",
    "body": "",
    "created_at": "2026-05-30T12:00:00Z"
  }
]
```

Каждая заметка содержит:

- `id` — уникальный идентификатор
- `title` — заголовок заметки
- `body` — текст заметки
- `created_at` — время создания в ISO 8601
