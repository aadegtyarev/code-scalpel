# CLI для заметок

## Команды:
- **add**: добавляет новую заметку.
  Пример использования: `python main.py add "Новая заметка"`
- **list**: выводит все сохраненные заметки.
  Пример использования: `python main.py list`
- **search**: ищет заметки по ключевым словам.
  Пример использования: `python main.py search "ключевое слово"`
- **delete**: удаляет заметку по идентификатору.
  Пример использования: `python main.py delete 1`
