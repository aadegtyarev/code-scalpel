# Программа для работы с заметками

## Описание
Программа предоставляет простой интерфейс командной строки для добавления, просмотра, поиска и удаления заметок. Все данные сохраняются в JSON-файле.

## Команды

### add
Добавляет новую заметку.
**Использование:**
```
python -m notes.cli add "Название заметки" "Текст заметки"
```

### list
Выводит список всех заметок.
**Использование:**
```
python -m notes.cli list
```

### search
Ищет заметки по названию или тексту.
**Использование:**
```
python -m notes.cli search "Поисковая строка"
```

### delete
Удаляет заметку по её идентификатору.
**Использование:**
```
python -m notes.cli delete <идентификатор>
```
