# notes-cli

Консольный менеджер заметок. Хранит заметки в JSON-файле, предоставляет
четыре команды: **add**, **list**, **search**, **delete**.

## Установка

```bash
pip install -e .
```

## Команды

### `notes add`

Создаёт новую заметку. Принимает флаги `--title` и `--body`.
Выводит присвоенный `id`.

```bash
notes add --title "Купить молоко" --body "Зайти в магазин по пути с работы"
# → Заметка добавлена, id: 1
```

### `notes list`

Выводит все заметки.

```bash
notes list
# → 1. Купить молоко
#    Зайти в магазин по пути с работы
```

### `notes search`

Ищет заметки по подстроке в заголовке или теле (регистронезависимо).

```bash
notes search молоко
# → 1. Купить молоко
#    Зайти в магазин по пути с работы
```

### `notes delete`

Удаляет заметку по `id`.

```bash
notes delete 1
# → Заметка 1 удалена
```

## Формат хранения

Файл: `notes.json` (создаётся в рабочей директории).

```json
[
  {
    "id": 1,
    "title": "Купить молоко",
    "body": "Зайти в магазин по пути с работы"
  }
]
```

Каждая заметка — объект с тремя полями:

| Поле   | Тип   | Описание                  |
|--------|-------|---------------------------|
| `id`   | int   | Уникальный числовой id    |
| `title`| str   | Заголовок заметки         |
| `body` | str   | Текст заметки             |

Файл — это JSON-массив объектов. Если файла нет, он создаётся при
первом добавлении. `id` увеличивается на 1 на основе максимального
существующего id.
