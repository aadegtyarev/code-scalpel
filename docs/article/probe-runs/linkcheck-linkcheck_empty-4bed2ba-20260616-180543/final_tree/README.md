# Link Checker

Утилита для поиска и проверки ссылок в Markdown (`.md`) файлах. Рекурсивно обходит все `.md` файлы в проекте, извлекает из них URL-ссылки и проверяет их доступность через HTTP-запросы.

## Установка

```bash
pip install -e .
```

## Команды

### Извлечение ссылок

Сканирует все `.md` файлы в проекте и выводит список найденных ссылок для каждого файла.

```bash
python link_checker.py --extract
```

Пример вывода:

```
# README.md
  https://example.com
  https://python.org

# docs/guide.md
  https://docs.python.org/3/
  ./local-file.md
```

### Проверка ссылок

Для каждой найденной ссылки выполняет HTTP-запрос (HEAD, при ошибке — GET) и сообщает о доступности.

```bash
python link_checker.py --check
```

Пример вывода:

```
✓ README.md:3  https://python.org  →  200 OK
✗ README.md:5  https://example.com/404  →  404 Not Found
✗ docs/guide.md:10  https://does.not.exist  →  ConnectionError (таймаут)
✓ docs/guide.md:12  ./local-file.md  →  файл найден
```

### Справка

```bash
python link_checker.py --help
```

## Формат вывода

- **Извлечение** (`--extract`): для каждого файла выводится его путь и список ссылок (по одной на строке с отступом).
- **Проверка** (`--check`): каждая ссылка на отдельной строке. Префикс `✓` — ссылка доступна, `✗` — битая ссылка. Формат: `префикс файл:строка ссылка → статус`.
- **Ошибки**: при недоступности ссылки выводится HTTP-код (404, 500) или тип исключения (ConnectionError, Timeout, SSLError).

## Обработка ошибок

- При недоступности сервера или таймауте ссылка считается битой, в отчёте указывается тип ошибки.
- Локальные/относительные ссылки проверяются на существование файла относительно расположения `.md` файла.
- Якоря (`#section`) игнорируются при проверке — проверяется только URL до якоря.
- Если не удаётся установить соединение с сервером, утилита переходит к следующей ссылке без остановки всего сканирования.

## Требования

- Python ≥ 3.11
- Зависимости: `requests` (будет установлена при `pip install -e .`)
