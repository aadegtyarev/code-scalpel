# CLI для заметок

## Команды:

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes.py add "Моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```bash
python notes.py search "заметка"
```

### delete
Удаляет заметку по её индексу.

**Пример использования:**
```bash
python notes.py delete 1
```

## Формат хранения данных:
Заметки сохраняются в файл `notes.json` в формате JSON-массива строк.
