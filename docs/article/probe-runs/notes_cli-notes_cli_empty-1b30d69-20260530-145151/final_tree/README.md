# CLI для заметок

Этот проект представляет собой простой CLI (Command Line Interface) для управления заметками. Заметки хранятся в формате JSON.

## Команды:
- **add**: Добавляет новую заметку.
  Пример использования: `python cli.py add "Моя первая заметка"`
- **list**: Выводит список всех заметок.
  Пример использования: `python cli.py list`
- **search**: Ищет заметки по ключевому слову.
  Пример использования: `python cli.py search "ключевое слово"`
- **delete**: Удаляет заметку по её индексу.
  Пример использования: `python cli.py delete 1`
