# Python Notes CLI

Простой интерфейс командной строки для управления заметками. Данные хранятся в локальном JSON-файле.

## Команды

### `add <text>`
Добавляет новую заметку. Каждой заметке автоматически присваивается уникальный ID.
**Пример:**
```bash
python main.py add "Купить молоко"
```

### `list`
Выводит список всех существующих заметок с их ID и текстом.
**При	мер:**
```bash
python main.py list
```

### `search <query>`
Ищет заметки, содержащие указанную подстроку в тексте.
**Пример:**
```bash
python main.py search "молоко"
```

### `delete <id>`
Удаляет заметку по её идентификатору.
**Пример:**
```bash
python main.py delete 1
```

## Формат хранения данных

Данные хранятся в файле `notes.json` в следующем формате:
```json
[
  {
    "id": 1,
    "text": "Первая заметка",
    "created_at": "2023-10-27T10:00:00"
  },
  {
    "id": 2,
    "text": "Вторая заметка",
    "created_at": "2023-10-27T10:05:00"
  }
]
```

## Структура проекта

- `main.py` — точка входа (CLI layer).
- `notes_app/` — основной пакет приложения.
    - `storage.py` — слой работы с JSON (Storage layer).
    - `service.py` — бизнес-логика (Service layer).
- `tests/` — набор тестов на pytest.
- `pyproject.toml` — конфигурация проекта и зависимостей.

## Запуск тестов

Для запуска всех тестов используйте:
```bash
pytest
```
