# notes-cli

Python CLI для управления заметками с JSON-хранилищем.

## Установка

```bash
pip install -e .
```

## Команды

### add

Добавить новую заметку.

```bash
notes add --title "Заголовок" --content "Текст заметки"
```

Выводит ID созданной заметки.

### list

Вывести все заметки.

```bash
notes list
```

### search

Поиск заметок по заголовку или тексту.

```bash
notes search --query "ключевое слово"
```

### delete

Удалить заметку по ID.

```bash
notes delete --id 1
```

## Хранение данных

Заметки сохраняются в JSON-файл `notes.json` в текущей рабочей директории.
Формат файла:

```json
[
  {
    "id": 1,
    "title": "Заголовок",
    "content": "Текст заметки",
    "created_at": "2024-01-01T12:00:00"
  }
]
```
