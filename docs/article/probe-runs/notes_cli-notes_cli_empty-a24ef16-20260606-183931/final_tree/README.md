# Python Notes CLI

## Описание
Этот проект представляет собой простой командный интерфейс для управления заметками. Он позволяет добавлять, просматривать, искать и удалять заметки с использованием JSON-хранилища.

## Команды CLI

- **add**: Добавляет новую заметку.
  ```bash
  python notes.py add "Ваша заметка"
  ```

- **list**: Показывает все сохраненные заметки.
  ```bash
  python notes.py list
  ```

- **search**: Ищет заметки по ключевому слову.
  ```bash
  python notes.py search "ключевое_слово"
  ```

- **delete**: Удаляет заметку по индексу.
  ```bash
  python notes.py delete <индекс>
  ```
