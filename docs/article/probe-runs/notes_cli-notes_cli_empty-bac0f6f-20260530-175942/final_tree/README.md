# Notes CLI

## Описание
Этот проект представляет собой простой Python-CLI для управления заметками. Команды позволяют добавлять, просматривать, искать и удалять заметки.

## Установка
1. Создайте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Команды
- **add**: Добавляет новую заметку.
  Пример использования:
  ```bash
  python notes.py add "Моя первая заметка"
  ```

- **list**: Выводит список всех заметок.
  Пример использования:
  ```bash
  python notes.py list
  ```

- **search**: Ищет заметки по ключевым словам.
  Пример использования:
  ```bash
  python notes.py search "заметка"
  ```

- **delete**: Удаляет заметку по её индексу.
  Пример использования:
  ```bash
  python notes.py delete 1
  ```

## Формат хранения данных
Заметки сохраняются в файле `storage.json` в формате JSON. Каждая заметка представляет собой строку текста.
