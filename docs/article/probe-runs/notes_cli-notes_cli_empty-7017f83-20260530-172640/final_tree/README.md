# CLI для заметок

Этот проект представляет собой простой Python-CLI для управления заметками. Заметки хранятся в JSON-файле.

## Команды

1. **add**
   Добавляет новую заметку.
   ```bash
   python notes.py add "Это моя первая заметка"
   ```

2. **list**
   Отображает все заметки.
   ```bash
   python notes.py list
   ```

3. **search**
   Ищет заметки по ключевому слову.
   ```bash
   python notes.py search "заметка"
   ```

4. **delete**
   Удаляет заметку по идентификатору.
   ```bash
   python notes.py delete 1
   ```
