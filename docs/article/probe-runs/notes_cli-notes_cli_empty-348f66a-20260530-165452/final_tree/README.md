# CLI для заметок

## Команды:

- `add <текст>`: добавляет новую заметку.
  Пример: `python notes/cli.py add "Моя первая заметка"`

- `list`: выводит список всех заметок.
  Пример: `python notes/cli.py list`

- `search <ключевое слово>`: ищет заметки по ключевому слову.
  Пример: `python notes/cli.py search "заметка"`

- `delete <индекс>`: удаляет заметку по её индексу в списке.
  Пример: `python notes/cli.py delete 1`
