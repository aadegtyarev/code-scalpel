# CLI для заметок

## Описание
Этот проект представляет собой простой CLI-инструмент для управления заметками. Заметки хранятся в JSON-файле.

## Команды

1. **add**
   Добавляет новую заметку.
   ```bash
   python notes.py add "Встреча с коллегами"
   ```

2. **list**
   Выводит все сохраненные заметки.
   ```bash
   python notes.py list
   ```

3. **search**
   Ищет заметки по ключевому слову.
   ```bash
   python notes.py search "встреча"
   ```

4. **delete**
   Удаляет заметку по её индексу (начинается с 0).
   ```bash
   python notes.py delete 0
   ```
