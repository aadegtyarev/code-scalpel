# Notes CLI

## Описание
Этот проект представляет собой простой Python-CLI для управления заметками. Команды позволяют добавлять, отображать, искать и удалять заметки.

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes/cli.py add "Моя первая заметка"
```

### list
Отображает список всех заметок.

**Пример использования:**
```bash
python notes/cli.py list
```

### search
Ищет заметки по ключевому слову или фразе.

**Пример использования:**
```bash
python notes/cli.py search "заметка"
```

### delete
Удаляет заметку по её индексу в списке.

**Пример использования:**
```bash
python notes/cli.py delete 1
```

## Формат хранения данных
Заметки сохраняются в формате JSON в файл `notes.json`.
