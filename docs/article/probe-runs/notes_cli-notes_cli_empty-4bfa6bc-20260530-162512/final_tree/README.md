# CLI для заметок

## Описание
Этот проект предоставляет простой CLI-интерфейс для управления заметками. Заметки хранятся в формате JSON.

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```bash
python notes.py add "Это моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример использования:**
```bash
python notes.py list
```

### search
Ищет заметки по ключевым словам.

**Пример использования:**
```bash
python notes.py search "заметка"
```

### delete
Удаляет заметку по её идентификатору.

**Пример использования:**
```bash
python notes.py delete 1
```
