# Программа для заметок

Этот проект представляет собой простой Python-CLI для управления заметками. Основные функции включают добавление, просмотр, поиск и удаление заметок.

## Команды CLI

1. **add**
   Добавляет новую заметку.
   ```bash
   python notes/cli.py add "Вот моя новая заметка"
   ```

2. **list**
   Выводит все сохраненные заметки.
   ```bash
   python notes/cli.py list
   ```

3. **search**
   Ищет заметки по введенному тексту.
   ```bash
   python notes/cli.py search "текст для поиска"
   ```

4. **delete**
   Удаляет заметку по её индексу или идентификатору.
   ```bash
   python notes/cli.py delete 1
   ```
