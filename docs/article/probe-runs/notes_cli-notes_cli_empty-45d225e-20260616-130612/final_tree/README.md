# notes-cli

Консольная утилита для управления заметками с хранением в JSON-файле.

## Команды

Все команды запускаются через `python cli.py`.

### add

Добавить новую заметку. Принимает заголовок и содержимое (оба обязательны).

```bash
python cli.py add --title "Купить молоко" --content "Заехать в магазин после работы"
python cli.py add --title "Идея для проекта" --content "CLI-органайзер на Python"
```

### list

Показать все заметки. Если заметок нет — выводит `No notes found.`

```bash
python cli.py list
```

Пример вывода:

```
1. Купить молоко
2. Идея для проекта
```

### search

Найти заметки по тексту (регистронезависимый поиск по заголовку и содержимому).

```bash
python cli.py search --query "молоко"
```

Если совпадений нет — выводит `No matches.`

### delete

Удалить заметку по её id.

```bash
python cli.py delete --id 1
```

При успехе: `Deleted note 1`.  
Если заметка с таким id не найдена: `Note 1 not found.` (код возврата 1).

## Формат хранения

Заметки сохраняются в файл `notes.json` в текущей директории.  
Структура каждой заметки:

```json
{
  "id": 1,
  "title": "Купить молоко",
  "content": "Заехать в магазин после работы"
}
```

Файл создаётся автоматически при первом добавлении заметки.  
Если файл отсутствует или пуст — список заметок считается пустым.

## Тесты

Проект использует [pytest](https://docs.pytest.org/). Запуск:

```bash
pytest -v
```
