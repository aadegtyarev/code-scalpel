# Программа для заметок

Этот проект представляет собой простой CLI-инструмент для управления заметками. Он поддерживает следующие команды:

## Команды

- **add**: Добавляет новую заметку.
  ```bash
  python app.py add "Ваша заметка"
  ```

- **list**: Выводит список всех заметок.
  ```bash
  python app.py list
  ```

- **search**: Ищет заметки по ключевому слову.
  ```bash
  python app.py search "ключевое_слово"
  ```

- **delete**: Удаляет заметку по её индексу.
  ```bash
  python app.py delete <индекс>
  ```

## Формат хранения данных

Заметки хранятся в JSON-файле `storage.json`.
