# Notes CLI

## Команды

### add
Добавляет новую заметку.

**Пример:**
```bash
python main.py add "Это моя первая заметка"
```

### list
Выводит список всех заметок.

**Пример:**
```bash
python main.py list
```

### search
Ищет заметки по ключевым словам.

**Пример:**
```bash
python main.py search "заметка"
```

### delete
Удаляет заметку по индексу.

**Пример:**
```bash
python main.py delete 1
```

## Формат хранения данных
Заметки сохраняются в файл `notes.json` в формате JSON массива строк.
