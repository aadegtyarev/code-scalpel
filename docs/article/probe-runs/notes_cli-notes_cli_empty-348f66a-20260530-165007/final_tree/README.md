# CLI для заметок

Команды:
- add: добавляет новую заметку.
  Пример: `python main.py add "Новая заметка"`

- list: отображает все заметки.
  Пример: `python main.py list`

- search: ищет заметки по ключевым словам.
  Пример: `python main.py search "ключевое слово"`

- delete: удаляет заметку по идентификатору.
  Пример: `python main.py delete 1`
