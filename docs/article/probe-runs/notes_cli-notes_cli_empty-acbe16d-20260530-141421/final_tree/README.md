# CLI для заметок

## Команды:

- `add <заметка>`: добавляет новую заметку.
  Пример использования: `python notes.py add 'Позвонить маме'

- `list`: выводит все заметки.
  Пример использования: `python notes.py list`

- `search <ключевое слово>`: ищет заметки по ключевому слову.
  Пример использования: `python notes.py search 'Позвонить'

- `delete <номер заметки>`: удаляет заметку по её номеру.
  Пример использования: `python notes.py delete 1
