# Notes CLI

A simple Python-based CLI for managing notes with commands to add, list, search, and delete notes.

## Commands

- **add**: Add a new note.
  ```bash
  python notes/cli.py add "Your note text here"
  ```

- **list**: List all notes.
  ```bash
  python notes/cli.py list
  ```

- **search**: Search for notes containing a keyword.
  ```bash
  python notes/cli.py search "keyword"
  ```

- **delete**: Delete a note by index.
  ```bash
  python notes/cli.py delete <index>
  ```
