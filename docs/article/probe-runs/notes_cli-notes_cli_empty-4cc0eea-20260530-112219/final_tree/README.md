# CLI для заметок

## Описание проекта
Этот проект представляет собой простой Python-CLI для управления заметками. Он позволяет добавлять, просматривать, искать и удалять заметки с использованием JSON-файла как хранилища данных.

## Команды и примеры использования
### add
Добавляет новую заметку.
```bash
python notes.py add "Название заметки" "Текст заметки"
```

### list
Отображает все заметки.
```bash
python notes.py list
```

### search
Ищет заметки по ключевым словам.
```bash
python notes.py search "ключевое слово"
```

### delete
Удаляет заметку по названию.
```bash
python notes.py delete "Название заметки"
```

## Формат хранения данных
Заметки сохраняются в файле `storage.json` в формате JSON. Каждая заметка представляет собой объект с полями:
- `title`: название заметки (строка)
- `content`: текст заметки (строка)
