# CLI для заметок

## Описание
Этот проект предоставляет простой CLI для управления заметками. Заметки хранятся в формате JSON.

## Команды
- **add**: Добавить новую заметку.
  Пример использования: `python main.py add "Новая заметка"
- **list**: Вывести список всех заметок.
  Пример использования: `python main.py list`
- **search**: Найти заметки по ключевому слову.
  Пример использования: `python main.py search "ключевое слово"
- **delete**: Удалить заметку по индексу.
  Пример использования: `python main.py delete 1`

## Формат данных
Заметки хранятся в файле `notes.json` в формате:
```json
[
    {
        "id": 1,
        "text": "Первая заметка"
    },
    {
        "id": 2,
        "text": "Вторая заметка"
    }
]
```
