# CLI для заметок

Этот проект представляет собой простой CLI-интерфейс для управления заметками. Поддерживаются следующие команды:

## Команды

### add
Добавляет новую заметку.

**Пример использования:**
```
python notes.py add "Заметка о покупках"
```

### list
Выводит список всех заметок.

**Пример использования:**
```
python notes.py list
```

### search
Ищет заметки по ключевому слову.

**Пример использования:**
```
python notes.py search "покупки"
```

### delete
Удаляет заметку по её индексу в списке.

**Пример использования:**
```
python notes.py delete 1
```
