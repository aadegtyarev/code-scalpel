# Notes CLI

## Описание
Этот проект представляет собой простой Python-CLI для управления заметками. Заметки хранятся в JSON-файле.

## Команды
- `add <text>`: Добавляет новую заметку.
- `list`: Отображает все заметки.
- `search <keyword>`: Ищет заметки по ключевому слову.
- `delete <index>`: Удаляет заметку по её индексу.

## Формат хранения данных
Заметки сохраняются в файле `notes.json` в формате JSON, где каждый элемент массива представляет собой строку заметки.
