# Программа для заметок

Этот проект представляет собой простой CLI-инструмент для управления заметками. Поддерживаются следующие команды:

## Команды

- **add**: Добавляет новую заметку.
  ```bash
  python notes.py add "Ваша заметка"
  ```

- **list**: Выводит список всех заметок.
  ```bash
  python notes.py list
  ```

- **search**: Ищет заметки по ключевому слову.
  ```bash
  python notes.py search "ключевое_слово"
  ```

- **delete**: Удаляет заметку по её индексу.
  ```bash
  python notes.py delete 1
  ```

## Формат данных

Заметки хранятся в файле `notes.json` в формате JSON. Каждая заметка представляет собой строку текста.
