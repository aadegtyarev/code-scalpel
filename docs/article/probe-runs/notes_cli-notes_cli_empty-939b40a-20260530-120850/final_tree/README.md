# Notes CLI

## Описание
CLI приложение для управления заметками. Предоставляет следующие команды:

- `add <content>`: добавить новую заметку.
  Пример использования: `notes_cli add "Моя первая заметка"`

- `list`: вывести список всех заметок.
  Пример использования: `notes_cli list`

- `search <query>`: найти заметки по содержанию.
  Пример использования: `notes_cli search "заметка"`

- `delete <id>`: удалить заметку по её ID.
  Пример использования: `notes_cli delete 1`
