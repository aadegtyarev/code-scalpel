# Программа для заметок

Этот проект представляет собой простой CLI-инструмент для управления заметками. Основные команды:

## add
Добавляет новую заметку.
```bash
python notes.py add "Текст заметки"
```

## list
Выводит список всех заметок.
```bash
python notes.py list
```

## search
Ищет заметки по ключевому слову.
```bash
python notes.py search "ключевое_слово"
```

## delete
Удаляет заметку по её идентификатору.
```bash
python notes.py delete 123
```
